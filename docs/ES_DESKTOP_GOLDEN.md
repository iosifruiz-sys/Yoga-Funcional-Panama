# ES desktop golden baseline

The current Spanish desktop homepage is the approved visual baseline.

- **Golden commit:** `7129ebbaba3e8f323681954502430e37e330568b`
- **Git tag:** `es-desktop-golden`
- **Checkpoint date:** 2026-09-28

Future work on the Russian or mobile versions must not change the appearance of the Spanish desktop homepage without a separate, explicit instruction to do so.

Changes to shared components or global CSS must be checked for Spanish desktop regressions against this checkpoint.

If the Spanish desktop homepage is changed accidentally, restore the approved result from the commit or tag above rather than reconstructing it from memory.
